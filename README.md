# seoganglee.github.io

Seogang Lee 리서치 포트폴리오 홈페이지 — https://seoganglee.github.io

## 새 글 쓰는 법

1. `_templates/` 폴더에서 양식(시황노트 / 경제지표 / 매매일지)을 열어 내용을 복사합니다.
2. `_posts/` 폴더에서 **Add file → Create new file**을 누릅니다.
3. 파일 이름을 `날짜-영문제목.md` 형식으로 입력합니다. 예: `2026-11-19-us-market.md`
   - 날짜(YYYY-MM-DD)가 글의 날짜가 됩니다. 영문제목은 주소에 쓰이며 영문·숫자·하이픈만 쓰세요.
4. 양식을 붙여 넣고 내용을 채운 뒤 **Commit changes**를 누릅니다. 1~2분 뒤 홈페이지에 자동으로 올라갑니다.

## 규칙

- 맨 위 `---` 사이(머리말)는 홈페이지 카드·표에 쓰이는 정보입니다. 따옴표와 들여쓰기를 양식 그대로 유지하세요.
- `category`: `market`(시황 노트), `macro`(경제지표), `trade`(매매 일지) 중 하나.
- 변화율·수익률은 `+`로 시작하면 빨강, `-`로 시작하면 파랑으로 표시됩니다.
- 머리말 아래 본문은 마크다운으로 자유롭게 씁니다. 시황 노트는 첫 문단이 홈페이지 카드 요약으로 쓰입니다.
- 예시 글(`sample-`로 시작하는 파일)은 실제 글을 쓰고 나면 지워도 됩니다.
